Arquitetura

Como as camadas se comunicam

O sistema usa o padrão BFF (Backend for Frontend): o navegador só conversa com o Laravel.

Navegador (React)

Interface do usuário.
Recebe apenas cookie HttpOnly.
Zero chaves ou tokens.

→

API Laravel (BFF)

Valida sessão, CSRF e permissões.
Aplica Pepper, cache e registra logs.

→

Supabase & APIs

PostgreSQL (RLS + Triggers),
Supabase Auth (Hash + Salt)
e Google Books API.

Gestão & Segurança

Painel do Bibliotecário e Proteções

Acesso restrito a perfis cadastrados na tabela bibliotecarios.

Permissões (RBAC) Guard.jsx no React + EnsureBibliotecario na API bloqueiam rotas /admin para leitores comuns (HTTP 403).
Hash + Salt + Pepper Laravel aplica HMAC-SHA256 com PASSWORD_PEPPER antes do Supabase Auth gerar Salt único + Hash seguro.
SQL Injection (Prepared) 100% das queries usam Prepared Statements via Query Builder + escape em buscas ILIKE.
Gestão de Acervo Cadastro (com Google Books), edição e exclusão segura por id_livro protegendo histórico de empréstimos.
Estoque Atômico (Triggers) Transações com lockForUpdate() e triggers SQL reduzem/devolvem exemplares automaticamente.
Logs de Auditoria Registros automáticos de login, tentativas inválidas, solicitações, empréstimos, devoluções e exclusões.
